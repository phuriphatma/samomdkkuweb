## เราขออะไร

ขอรายชื่อนักศึกษาแพทย์ทั้งคณะ (ประมาณ 1,800 คน ชั้นปี 1–6)
เป็นไฟล์ตาราง **1 บรรทัด = นักศึกษา 1 คน** มี **7 ช่อง** ตามนี้

| ชื่อช่อง (พิมพ์ตามนี้) | คือ | ตัวอย่าง |
|---|---|---|
| `student_id` | รหัสนักศึกษา | `659999999-9` |
| `first_name_th` | ชื่อจริง (ภาษาไทย) | `มานี` |
| `last_name_th` | นามสกุล (ภาษาไทย) | `ใจดี` |
| `nickname_th` | ชื่อเล่น (ภาษาไทย) | `นก` |
| `kkumail` | อีเมล kkumail | `manee.j@kkumail.com` |
| `major` | สาขา | `MD` |
| `sai` | สายรหัส | `017` |

**ขอแค่ 7 ช่องนี้พอ** ไม่ต้องมีชั้นปี ไม่ต้องมีปีที่เข้าเรียน ไม่ต้องมีสถานะ
เราคำนวณเองได้จากรหัสนักศึกษา

**ชื่อช่องขอเป็นภาษาอังกฤษตามตารางข้างบน** พิมพ์ให้ตรงทุกตัวอักษร
วางไว้บรรทัดบนสุด บรรทัดเดียว
(ต้องเป็นภาษาอังกฤษเพราะโปรแกรมอ่านชื่อช่องตรงๆ ภาษาไทยมักเพี้ยนตอนเปิดไฟล์)

## กติกาการกรอกแต่ละช่อง

### รหัสนักศึกษา
- ใส่ขีดก่อนหลักสุดท้าย แบบนี้ `659999999-9`
- ถ้าระบบต้นทางไม่มีขีด ส่งเป็น `6599999999` ก็ได้ แต่ต้องเหมือนกันทั้งไฟล์
- ห้ามซ้ำ ถ้าซ้ำแปลว่ามีคนพิมพ์ผิด ต้องแก้ก่อนส่ง

### ชื่อ และ นามสกุล
- **แยกเป็น 2 ช่อง** ไม่ต้องรวมกัน
- ภาษาไทย
- **ไม่ต้องใส่คำนำหน้า** ไม่เอา `นาย` `นางสาว` `น.ส.`
- ไม่ต้องใส่ชื่อเล่นในวงเล็บต่อท้าย เช่น `มานี (นก)` แบบนี้ไม่เอา
  เพราะชื่อเล่นมีช่องของมันอยู่แล้ว
- นามสกุลที่มีหลายคำ เช่น `ณ อยุธยา` ใส่ทั้งหมดในช่องนามสกุล

### ชื่อเล่น
- ภาษาไทย คำเดียว ไม่ต้องมีวงเล็บ ไม่ต้องมีคำว่า `น้อง`
- ถ้าไม่มีข้อมูล **เว้นว่างไว้เลย** อย่าใส่ขีด `-`

### อีเมล kkumail — **ช่องที่สำคัญที่สุดในไฟล์**
- ใส่เต็ม มี `@kkumail.com` ด้วย เช่น `manee.j@kkumail.com`
- ตัวพิมพ์เล็กทั้งหมด ไม่มีเว้นวรรค
- **ห้ามเว้นว่าง ห้ามซ้ำ**
- **ทำไมถึงสำคัญ:** ช่องนี้คือตัวที่ระบบใช้จับคู่ตอนนักศึกษาเข้าสู่ระบบ
  ถ้าอีเมลผิดแม้แต่ตัวเดียว คนนั้นเข้ามาแล้วจะ **ไม่เจอข้อมูลตัวเอง**
  และแก้เองไม่ได้ ต้องมาแจ้งทีละคน
  ช่องอื่นผิดยังพอแก้ทีหลังได้ แต่ช่องนี้ผิดคือใช้ไม่ได้เลย

### สาขา
- ตัวพิมพ์ใหญ่ ไม่มีจุด: `MD` หรือ `MDI` หรือ `RT`
- อย่าใช้ `md` `M.D.` หรือ `แพทยศาสตร์`

### สายรหัส — **ช่องที่พลาดกันบ่อยที่สุด**
- **3 หลักเสมอ** เช่น `001` `017` `042` `100` `287` `999`
- **เลขสายเป็นอะไรก็ได้ตั้งแต่ `001` ถึง `999`** ไม่มีขีดจำกัด
  ส่งมาตามที่มหาวิทยาลัยกำหนดได้เลย ไม่ต้องกังวลว่าเลขจะเกิน
- ถ้าเลขไม่ครบ 3 หลัก **ให้เติมเลข 0 ข้างหน้าให้ครบ**
  สาย 1 เขียนเป็น `001` · สาย 17 เขียนเป็น `017`
- นี่คือสายรหัสของ **ระบบอาจารย์ที่ปรึกษาของมหาวิทยาลัย** ที่สุ่มให้นักศึกษา
  **ไม่ได้คิดมาจากรหัสนักศึกษา** กรุณาส่งค่าที่มหาวิทยาลัยกำหนดมาตามจริง
  **ห้ามเดา ห้ามคำนวณเอง**
- ถ้าคนไหนไม่มีข้อมูลสายรหัส ให้เว้นว่างไว้ แล้วบอกเราว่ามีกี่คน

> ### ⚠️ เรื่องเลข 0 ข้างหน้าหาย — อ่านตรงนี้ก่อนส่ง
>
> Excel และ Google Sheets จะ **ลบเลข 0 ข้างหน้าทิ้งเองอัตโนมัติ**
> `001` จะกลายเป็น `1` · `017` จะกลายเป็น `17` · `010` จะกลายเป็น `10`
>
> **ถ้าเกิดเรื่องนี้ ไฟล์จะใช้ไม่ได้เลย** เพราะระบบจะจัดนักศึกษาเข้ากลุ่มผิดคน
>
> **วิธีป้องกัน:** คลิกหัวคอลัมน์สายรหัสเพื่อเลือกทั้งคอลัมน์ →
> ตั้งรูปแบบเป็น **"ข้อความ" (Text)** → **แล้วค่อยพิมพ์หรือวางข้อมูลลงไป**
> (ต้องตั้งก่อนใส่ข้อมูล ถ้าใส่ไปแล้วค่อยมาตั้ง เลข 0 หายไปแล้ว)
>
> **วิธีตรวจก่อนส่ง:** ดูในไฟล์ว่ายังเห็น `001` แบบมีเลข 0 ครบไหม
> ถ้าเห็นเป็น `1` เฉยๆ แปลว่าหายแล้ว ต้องทำใหม่

## กติกาทั่วไป

1. **1 บรรทัด = 1 คน** ห้ามมีบรรทัดว่าง ห้ามมีบรรทัดสรุปยอด
2. หัวตารางบรรทัดเดียว อยู่บนสุด
3. ห้ามรวมช่อง (merge cell) · ห้ามใช้สีแทนความหมาย · ห้ามมีชีตซ่อน
4. **ช่องไหนไม่มีข้อมูล ให้เว้นว่างจริงๆ**
   อย่าใส่ `-` `N/A` `ไม่มี` `ยังไม่ทราบ`
   (ถ้าใส่ ระบบจะเก็บเป็นข้อมูลจริง แล้วไปโผล่บนหน้าโปรไฟล์ของนักศึกษา)
5. อย่าให้มีเว้นวรรคเกินหน้า-หลังข้อความ
6. ใช้เลขอารบิก `0-9` อย่าใช้เลขไทย `๐๑๒๓`
7. **ห้ามมีคนซ้ำ** ทั้งรหัสนักศึกษาและอีเมล

### ส่งไฟล์แบบไหนดี
- **ดีที่สุด: Google Sheets** แล้วแชร์ลิงก์มาให้ (ไม่มีปัญหาภาษาไทยเพี้ยน)
- ถ้าส่งเป็นไฟล์: บันทึกเป็น **CSV UTF-8**
  ใน Excel เลือก `Save As` → `CSV UTF-8`
  ถ้าเลือก `CSV` เฉยๆ ภาษาไทยจะกลายเป็นตัวประหลาด
- ไฟล์ Excel `.xlsx` ก็รับได้

## ข้อมูลที่ **ไม่ต้องส่ง**

ไฟล์นี้มีอีเมลกับรหัสนักศึกษาของนักศึกษา 1,800 คน ถือเป็นข้อมูลส่วนบุคคล
เราขอเท่าที่จำเป็นจริงๆ และ **ไม่ต้องการ** สิ่งเหล่านี้ กรุณาอย่าใส่มา

- เกรด / GPA / ผลการเรียน
- เบอร์โทร · ที่อยู่ · Line ID
- เลขบัตรประชาชน · วันเกิด
- ข้อมูลสุขภาพ · ข้อมูลผู้ปกครอง · ข้อมูลทุน
- รูปถ่าย

**ตอนส่ง** ขอเป็นลิงก์ที่จำกัดสิทธิ์เฉพาะผู้รับ
กรุณาอย่าตั้งเป็นลิงก์สาธารณะ และอย่าโพสต์ลงกลุ่มแชท

## ตรวจ 5 ข้อนี้ก่อนส่ง (ไม่ถึง 5 นาที)

1. จำนวนบรรทัดเท่ากับจำนวนนักศึกษาที่ควรจะมี
2. ไม่มีใครที่ช่องอีเมลว่าง
3. ไม่มีอีเมลซ้ำ และไม่มีรหัสนักศึกษาซ้ำ
4. **สายรหัสทุกคนยาว 3 หลักเท่ากันหมด** (เลข 0 ข้างหน้าไม่หาย)
5. ช่องที่ไม่มีข้อมูลเว้นว่างไว้ ไม่ได้ใส่ `-`

## ตัวอย่างไฟล์

ไฟล์ตัวอย่างพร้อมใช้: `docs/templates/house-import-template.csv`

```csv
student_id,first_name_th,last_name_th,nickname_th,kkumail,major,sai
659999999-9,มานี,ใจดี,นก,manee.j@kkumail.com,MD,017
669999998-8,ปิติ,รักเรียน,ต้น,piti.r@kkumail.com,MD,003
679999997-7,ชูใจ,ดีงาม,แก้ว,choojai.d@kkumail.com,MD,032
689999996-6,วีระ,ตั้งใจ,,weera.t@kkumail.com,MD,001
659999995-5,สุดา,ณ ลำปาง,ดาว,suda.n@kkumail.com,MDI,100
```

จุดที่อยากให้สังเกต
- บรรทัดที่ 4 ไม่มีชื่อเล่น → **เว้นว่าง** ไม่ได้ใส่ `-`
- สายรหัส `003` และ `001` → **เลข 0 ข้างหน้าอยู่ครบ**
- บรรทัดที่ 5 นามสกุล `ณ ลำปาง` มี 2 คำ → อยู่ในช่องนามสกุลทั้งก้อน

## ไฟล์ที่ 2 — อาจารย์ที่ปรึกษาแต่ละสาย (ขอทีหลังได้)

ยังไม่ต้องส่งพร้อมกัน แต่บอกรูปแบบไว้ก่อน
**1 บรรทัด = อาจารย์ 1 ท่าน ต่อ 1 สาย**
ถ้าอาจารย์ท่านเดียวดูแลหลายสาย ให้ใส่หลายบรรทัด ใช้อีเมลเดิม

| ชื่อช่อง | คือ | ตัวอย่าง |
|---|---|---|
| `sai` | สายรหัส (3 หลักเหมือนไฟล์แรก) | `017` |
| `advisor_title` | คำนำหน้าทางวิชาการ (แยกออกจากชื่อ) | `ผศ.` `รศ.` `นพ.` |
| `advisor_first_name_th` | ชื่อจริง | `สมชาย` |
| `advisor_last_name_th` | นามสกุล | `ใจดี` |
| `advisor_email` | อีเมลที่ติดต่อได้จริง | `somchai@kku.ac.th` |
| `advisor_dept` | ภาควิชา / สังกัด | `ภาควิชาอายุรศาสตร์` |

สายไหนยังไม่มีอาจารย์ **ไม่ต้องใส่บรรทัดเปล่า** ข้ามไปเลย
เราดูออกเองว่าสายไหนยังว่าง
