ข้อเสนอ: เอาแบบ ข เป็นเนื้อหา และเอา 3D เป็นภาพเปิด ถ้าอยากได้

เรื่องที่ร้องเรียนคือ “บนมือถือดูไม่ดี ความกว้างแสดงได้คอลัมน์เดียว” ซึ่งเป็นปัญหาการวาง ไม่ใช่ปัญหามิติ 3D ไม่ได้ทำให้ชื่อ 398 ชื่ออ่านง่ายขึ้นบนจอหกนิ้ว และมันแลกด้วยการค้นหา การอ่านออกเสียง ลิงก์ตรง และไฟล์อีกเจ็ดแสนไบต์ แต่ 3D เก่งอีกอย่างที่แบบ ข ทำไม่ได้เลย คือทำให้คน “อ๋อ องค์กรหน้าตาแบบนี้” ในสามวินาทีแรก

  1. เปลี่ยนการวางบนมือถือก่อน — คนเรียงเป็นตาราง 4 คอลัมน์ ฝ่ายพับได้ ชิปฝ่ายติดบน ความลึกเป็นข้อความบอกทางแทนการย่อหน้า นี่คือแบบ ข และไม่ต้องเพิ่มไลบรารีอะไรเลย
  2. ค่อยตัดสินใจเรื่อง 3D แยกกัน — ถ้าเอา ให้เป็นภาพเปิดสูงประมาณ 40% ของจอ อยู่เหนือรายการ กดข้ามได้ และโหลดแบบ lazy เฉพาะตอนเลื่อนมาถึง คนที่เข้ามาหาชื่อจะไม่ต้องจ่ายค่าไฟล์นั้น
  3. ถ้าอยากได้แค่ลุค 3D ไม่ต้องใช้ three.js — ภาพหมุนแบบในกรอบ ค วาดด้วย canvas ธรรมดาได้ ใช้โค้ดราวร้อยบรรทัด โหลดเพิ่ม 0 KB ต่างกันตรงที่ไม่มีแสงเงาและวัสดุจริง ซึ่งผังจุดกับเส้นไม่ได้ใช้อยู่แล้ว
