# ตัวอย่างเครื่องมือฝ่าย (starter)

Owner: ฝ่ายไอที (IT) — ไฟล์ตั้งต้น ไม่ใช่เครื่องมือจริง
Data: ตัวเลขสมมติใน `data.js` ไม่ได้มาจากที่ไหน
Updated by: ฝ่ายที่คัดลอกโฟลเดอร์นี้ไปใช้

---

## เริ่มยังไง

1. คัดลอกโฟลเดอร์นี้เป็นชื่อเครื่องมือของคุณ
   `public/embed/starter/` → `public/embed/golden-period/`
2. แก้ `index.html` และ `data.js` ได้ตามใจ
   **ดับเบิลคลิก `index.html` เพื่อดูผลได้เลย** ไม่ต้องติดตั้งอะไร
3. แก้ `README.md` ให้บอกว่าใครเป็นเจ้าของและข้อมูลมาจากไหน
   บรรทัด `Owner:` ต้องมี ไม่งั้น CI จะไม่ผ่าน
4. เปิด Pull Request จาก branch ชื่อขึ้นต้นว่า `tool/`
   เช่น `tool/golden-period`
5. ให้เจ้าของเว็บเพิ่มรายการหนึ่งบรรทัดใน `src/data/tools.js`
   หน้าถึงจะขึ้นที่ `/tools/<ชื่อโฟลเดอร์>`

📌 ข้อ 5 ทำได้เฉพาะเจ้าของเว็บ เพราะไฟล์นั้นคือจุดที่ตัดสินว่าอะไรเข้าถึงได้บ้าง
ส่วนไฟล์ในโฟลเดอร์นี้ เพื่อนร่วมทีมคนไหนก็อนุมัติได้

## ทำอะไรได้ ทำอะไรไม่ได้

หน้านี้รันอยู่ใน **กรอบที่ถูกกันออกจากเว็บหลัก** เพื่อให้เครื่องมือของฝ่าย
พังได้โดยไม่ทำให้เว็บพัง และไม่ต้องให้ไอทีตรวจโค้ดทุกบรรทัด

| ทำได้ | ทำไม่ได้ |
|---|---|
| HTML / CSS / JavaScript อะไรก็ได้ | อ่านชื่อผู้ใช้ที่ล็อกอิน |
| รูป ไฟล์ ข้อมูล ที่อยู่ในโฟลเดอร์นี้ | อ่านฐานข้อมูล (นั่นคือ Lane C — ต้องขอไอที) |
| ลิงก์ออกไปเว็บอื่น (เปิดแท็บใหม่) | `localStorage` / `sessionStorage` (จะ error) |
| ฟอร์มธรรมดา | `parent.` / `top.` (ยกเว้นบรรทัดบอกความสูง) |
| | เรียก API ข้างนอก (ส่ง `Origin: null` ส่วนใหญ่ถูกปฏิเสธ) |
| | ติดตั้ง npm / มี build step |

**ข้อมูลจึงอยู่ใน `data.js`** อัปเดตข้อมูล = แก้ไฟล์นั้นแล้วเปิด PR
ข้อดีคือหน้ายังใช้ได้ตอน Google ล่ม และตัวเลขที่เปลี่ยนจะเห็นชัดใน PR

## หกบรรทัดที่ห้ามลบ

ท้าย `index.html` มีโค้ดบอกความสูงของหน้าให้เว็บแม่รู้
เว็บแม่วัดความสูงเองไม่ได้ (กรอบถูกกันไว้) ถ้าลบออก กรอบจะสูงค้างที่ 70%
ของจอแล้วเลื่อนข้างในแทน — ไม่พัง แต่ไม่สวย

## ถ้าใช้ Claude ช่วยเขียน

บอกมันแค่นี้พอ:

> แก้ไฟล์ใน `public/embed/<ชื่อโฟลเดอร์>/` เท่านั้น
> อ่านกฎใน `README.md` ในโฟลเดอร์นั้นก่อน ห้ามแตะไฟล์อื่นในโปรเจกต์

⛔ **อย่าให้มันอ่าน `STATE.md` หรือ `.claude/rules/`** — เขียนไว้สำหรับคนที่แก้
โค้ดหลัก ถ้าอ่านแล้วมันจะพยายามไป deploy หรือแก้ฐานข้อมูลให้ (docs/DEPT-TOOLS.md §7)
