# กฎสำหรับ Claude ในโฟลเดอร์นี้

คุณกำลังช่วยฝ่ายทำ **หน้าเครื่องมือหนึ่งหน้า** ของเว็บ SAMO MDKKU

## ขอบเขต — ข้อเดียวที่สำคัญที่สุด

**แก้ได้เฉพาะไฟล์ในโฟลเดอร์นี้** (`public/embed/<slug>/`)
ห้ามแตะ `src/`, `supabase/`, `server/`, `tools/`, `package.json` หรือไฟล์อื่นใด
ถ้าคิดว่าต้องแก้ไฟล์นอกโฟลเดอร์ ให้บอกผู้ใช้ว่าต้องขอเจ้าของเว็บ อย่าแก้เอง

CI จะปฏิเสธ Pull Request ที่แตะไฟล์นอกโฟลเดอร์นี้อยู่แล้ว

## หน้านี้รันในกรอบที่ถูกกันออกจากเว็บหลัก (sandbox, opaque origin)

ดังนั้น **อย่าเขียนโค้ดเหล่านี้ มันจะ error หรือถูกปฏิเสธเงียบๆ**

- `localStorage` / `sessionStorage` — throw ทันที
- `parent.` / `top.` / `window.opener` — ยกเว้น `parent.postMessage(` บรรทัดบอกความสูง
- `fetch()` ไปเว็บนอก — ส่ง `Origin: null` ส่วนใหญ่ถูกปฏิเสธ
- `<script src="https://...">` จาก CDN — อนุญาตเฉพาะ `cdn.jsdelivr.net`
  และ `cdnjs.cloudflare.com` นอกนั้น CI ไม่ผ่าน ให้เขียนโค้ดเองแทน
- npm / bundler / build step — ไม่มี ไฟล์ต้องเปิดด้วยการดับเบิลคลิกแล้วทำงานได้
- ล็อกอิน ชื่อผู้ใช้ สิทธิ์ ฐานข้อมูล — เข้าถึงไม่ได้เลยในเลนนี้

## ข้อมูล

ตัวเลขและข้อความที่ต้องอัปเดตบ่อย ให้อยู่ใน `data.js` เป็น object ธรรมดา
ไม่ใช่ hardcode ใน `index.html` และไม่ใช่ดึงจาก Google Sheet ตอนเปิดหน้า

## สิ่งที่ต้องคงไว้

- โค้ด `reportHeight()` ท้าย `index.html` — เว็บแม่ใช้บอกความสูงของกรอบ
- `README.md` ต้องมีบรรทัด `Owner:` ระบุคน CI เช็ค
- ใช้ตัวแปรสีจาก `TOKENS.css` เพื่อให้หน้ากลมกลืนกับเว็บ

## ภาษา

ผู้อ่านคือนักศึกษาแพทย์ไทย เขียนภาษาไทย ไม่ใส่อีโมจิในข้อความบนหน้าเว็บ
